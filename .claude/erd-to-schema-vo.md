# ERD 기반 VO(schema) 파일 생성 프롬프트

## 목적

ERD 이미지를 참고해 `schemas` 폴더에 테이블별 VO 파일을 만든다.

## 입력 자료

| 구분 | 경로 | 용도 |
| --- | --- | --- |
| ERD 이미지 | `C:\Users\user\Downloads\최종 중간프로젝트 erd (1).png` | 테이블, 컬럼, 타입, NULL 여부, 기본값, 관계 확인 |
| 백엔드 프로젝트 | `C:\kdt_0900_osh\fastapi\workspace\backend` | 파일 이름 규칙과 DTO 이름 규칙 참고 |

## 작업 내용

1. ERD 이미지를 읽고 테이블과 컬럼 정보를 정리한다.
2. 백엔드 프로젝트에서 다음 규칙을 확인한다.
   - 파일 이름 규칙 (예: 파일명 형식, 접미사, 대소문자)
   - DTO(클래스/타입) 이름 규칙
3. 확인한 규칙에 맞춰 `schemas` 폴더에 테이블별 VO 파일을 만든다.

## 제약 조건

- **기존 폴더는 절대 삭제하지 않는다.** 새 파일 추가만 한다.
- 파일 이름과 DTO 이름은 직접 정하지 말고 백엔드 프로젝트의 규칙을 따른다.

## 완료 기준

- ERD의 모든 테이블에 대응하는 VO 파일이 `schemas` 폴더에 있다.
- 파일 이름과 DTO 이름이 백엔드 프로젝트의 규칙과 일치한다.
- 기존 폴더와 파일은 그대로 남아 있다.
