# Merge 작업

현재 브랜치에서 `main`으로 이동한 뒤, 방금 있던 브랜치를 `main`에 merge해 줘.

## 사전 확인

- 현재 브랜치 이름을 기억해 둔다. (merge 대상 브랜치)
- 현재 브랜치가 이미 `main`이면 merge할 브랜치가 없으므로 작업하지 말고 알려준다.
- 커밋되지 않은 변경 사항이 있으면 작업하지 말고 먼저 알려준다.

```bash
git branch --show-current
```

## 작업 순서

### 1. main 브랜치로 이동

```bash
git checkout main
```

### 2. 방금 있던 브랜치를 main에 merge

```bash
git merge <방금 있던 브랜치>
```

- 충돌이 나면 임의로 해결하지 말고, 충돌난 파일 목록을 알려주고 어떻게 할지 물어본다.
- merge할 커밋이 없으면(이미 최신이면) 알려준다.

### 3. 결과 보고

- merge한 브랜치와 커밋 범위를 알려준다.
- 실패하면 에러 메시지와 원인을 알려준다.

## 주의 사항

- merge 후 브랜치 삭제나 push는 하지 않는다. (필요하면 사용자가 따로 요청한다.)
