# 클론 코딩 작업

`$1`에 지정된 예시 이미지(FewShot)를 참고해서 화면을 클론 코딩해 줘.

## 1. 사전 확인

- `$1`이 비어 있으면 작업을 시작하지 말고, 예시 이미지 경로를 알려 달라고 요청해 줘.
- 예시 이미지를 읽고, 레이아웃·색상·폰트·간격 등 화면 구성을 먼저 정리해 줘.

## 2. 구현

- 예시 이미지와 같은 구조(HTML 마크업, 레이아웃, 스타일)로 화면을 만들어 줘.
- 정적인 화면 구현에 집중하고, 아래 "하지 말아야 하는 것들"은 적용하지 마.

## 하지 말아야 하는 것들

1. CSS 애니메이션 (`@keyframes`, `transition`, `animation` 등)
2. JS 이벤트 효과 (호버·클릭에 따른 동적 효과, 스크롤 효과 등)

## 주의 사항

- 위 항목을 어기는 코드를 임의로 추가하지 마.
- 예시 이미지에 애니메이션이나 이벤트 효과가 보이더라도 정적인 모습만 구현해 줘.
- 예시 이미지를 확인할 수 없으면 추측으로 구현하지 말고, 원인을 알려 준 뒤 어떻게 할지 물어봐 줘.
