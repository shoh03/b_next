# 리스트 클론 코딩

예시 이미지를 참고해서 아래 리스트를 클론 코딩해 줘.

## 입력

### Few-shot 예시 이미지

<!-- $1: 첫 번째 인자. 참고할 예시 이미지 경로 -->
$1

### 리스트 목록

<!-- $ARGUMENTS: 전체 인자. 첫 번째 인자($1)는 이미지 경로이므로 리스트에서 제외한다 -->
$ARGUMENTS

## 작업 순서

1. **이미지 분석:** `$1` 이미지를 읽고 레이아웃, 색상, 폰트, 간격, 아이콘을 파악한다. 특히 리스트 항목 하나가 어떤 요소(예: 썸네일, 제목, 설명, 날짜, 가격, 버튼)로 어떻게 배치되어 있는지 정리한다.
2. **리스트 정리:** `$ARGUMENTS`에서 첫 번째 인자(이미지 경로)를 뺀 나머지를 리스트 항목으로 사용하고, 각 항목에 어떤 요소가 들어 있는지 파악한다.
3. **클론 코딩:** 이미지의 항목 구성과 스타일을 참고해 리스트 화면을 구현하되, **리스트 항목에 있는 요소만** 채운다.
   - 이미지에는 있지만 리스트 항목에 없는 요소는 만들지 않는다. (임의의 내용이나 placeholder로 채우지 않는다.)
   - 리스트 항목에 있는 요소는 이미지에서 같은 역할을 하는 요소의 위치와 스타일을 따른다.
4. **결과 보고:** 만든 파일, 그리고 이미지에서 빠진 요소나 다르게 구현한 부분(있다면)을 알려준다.

## 주의 사항

- 이미지 경로가 없거나 이미지를 읽을 수 없으면 작업하지 말고 알려준다.
- 리스트 항목이 없으면 이미지에 보이는 항목을 그대로 사용할지 먼저 물어본다.
- 프로젝트에 이미 쓰는 프레임워크/스타일 방식이 있으면 그것을 따른다.
